On the original Xbox and the Xbox 360, Microsoft identified games using a Title ID. Not only every different game would get a unique Title ID, but also non game physical releases, such as demos, utility discs, additional content discs, etc. If two variants of the same game have a different Title ID, the system will then consider them as separate games, since this is how it identifies a unique game. Updates and DLCs were also tied to a unique Title ID.

With the introduction of the Xbox Live Arcade, and the ability to download games, and later other things such as demos, apps, or others, this system was carried as well, and every downloadable content also has its own Title ID.


There's essentially 2 variations for this ID :


- A 5 or 6 character code. This code can be found on the original Xbox DVDs themselves, typically etched into the inner ring, or in the .XEX file of the Xbox 360 games. It is usually composed of 2 characters for the publisher, followed by an incremental game number (3 numbers for original Xbox, above 2000 for non-original Xbox games).

For example, for Microsoft's memfirst original Xbox game, Oddworld: Munch's Oddysee, the Title ID is MS-001 : MS for Microsoft, and 001 because it is their first game. Grand Theft Auto V's ID is TT-2215 : TT for the publisher, Take Two, and 2215 because it is their 215th non-original Xbox game.


- A 32 bit value, which is basically the Title ID code, but in hexadecimal digits. The 16 first bits/4 first hexadecimal digits numbers are basically the ASCII encoding of the 2-letter codes of each publisher. The 16 last bits are the game number in hexadecimal in digits.

If we keep the same examples, Oddworld: Munch's Oddysee Title ID is 4D530001 : in ASCII, 4D corresponds to M, and 53 to S, so 4D53 for MS, and 0001 is obviously the hexadecimal conversion of 1. Grand Theft Auto V's is 545408A7, 5454 for two times T, and 08A7 in hexadecimal equals 2215.


If you are looking for games that have variants with different Title IDs (for example, stackable games for achievement hunters), this article is what you are looking for.
